# TypeScript Assignment

## Overview

This repository contains my solutions to the TypeScript assignment. It covers various TypeScript concepts, including functions, union types,tuple, type narrowing, generics, interfaces, access modifiers, classes, and asynchronous programming.

## Repository Contents

- `solutions.ts` – Contains solutions to the assigned TypeScript problems.
- `type-narrowing.md` – Explains type narrowing in TypeScript, including `typeof`, `in`, and `instanceof` type guards.
- `access-modifiers.md` – Explains TypeScript access modifiers, including `public`, `private`, and `protected`, along with the `readonly` modifier.
